01ABOUT

Support taught me where software actually hurts.

I am Phi Hung. My day-to-day support mindset is simple: understand what the user is trying to do, find where the workflow breaks, and make the next attempt easier.

That naturally pulled me deeper into software engineering. I build web apps, desktop tools, APIs, scheduling systems, and experiments that connect real operational needs with practical code.

I care about readable interfaces, edge cases, permissions, testing, and maintainability — not only whether a feature works once.

⌘

Troubleshooting first

Reproduce the problem, isolate the cause, then fix the workflow instead of masking the symptom.

◇

Build for real use

Prefer small useful tools, clear states, sensible defaults, and feedback users can understand.

✓

Quality matters

Happy paths are not enough. I actively look for awkward cases, conflicts, permission issues, and failure states.
